# Aide de l'application

Cette application interne du CEN Champagne-Ardenne (CENCA) regroupe les informations sur les sites du Conservatoire : fiches site, maîtrise foncière, plans de gestion, travaux, suivis chiroptères, annuaire des partenaires. Cette aide explique comment vous en servir.

## Naviguer dans l'aide

- La liste des fiches d'aide s'affiche dans le menu à gauche. Cliquez sur un titre pour ouvrir la fiche.
- Le bouton menu, à gauche de la barre « Aide », affiche ou masque cette liste.
- Le titre de la fiche ouverte est rappelé à droite de la barre.
- Le bouton **Aide** de l'en-tête ouvre cette aide depuis n'importe quelle page. L'aide est réservée aux utilisateurs connectés.

Certaines fiches n'apparaissent que si vous avez les droits correspondants. Un lien vers une telle fiche affiche « Section introuvable. ».
