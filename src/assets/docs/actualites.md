# Actualités

Le fil d'actualités de la page d'accueil diffuse les informations internes. Vous pouvez y réagir et commenter ; les administrateurs les rédigent et les publient depuis la page Paramètres.

## Qui peut faire quoi

| Action | Qui |
| --- | --- |
| Lire les actualités, réagir, commenter | Tout utilisateur connecté |
| Supprimer un commentaire | Son auteur, ou un administrateur |
| Publier ou dépublier une actualité depuis sa fenêtre de détail | Administrateurs |
| Créer, modifier, supprimer une actualité | Administrateurs, depuis [Paramètres](/aide/parametres) |

## Lire le fil

Le bloc **Actualités** apparaît en haut de la page d'accueil. Chaque carte affiche la date (« il y a 3 h », « hier »... ; survolez-la pour voir la date exacte), le titre, le résumé, une image éventuelle, les réactions et le nombre de commentaires.

- Le fil affiche les actualités par paquets. Cliquez sur **Voir plus** en bas du fil pour charger les suivantes ; le bouton disparaît quand tout est affiché.
- Si aucune actualité n'est disponible, le bloc n'est pas affiché.

## Actualités non lues

- Une actualité que vous n'avez pas encore ouverte porte la mention **Nouveau** et un liseré de couleur.
- Le nombre d'actualités non lues est indiqué à côté du titre **Actualités** (par exemple « 2 nouvelles »).
- Une actualité est marquée comme lue dès que vous ouvrez sa fenêtre de détail.

## Ouvrir le détail

Cliquez sur une carte. La fenêtre de détail affiche le contenu complet, l'image, les réactions et les commentaires. Si l'actualité comporte un lien, un bouton **Aller voir dans ATLAS** l'ouvre dans un nouvel onglet.

Fermez la fenêtre avec la croix en haut à droite.

## Réagir

Cinq réactions sont proposées : **J'aime**, **J'adore**, **Nature**, **Bravo** et **Surpris** (survolez un bouton pour lire son nom). Vous pouvez réagir depuis la carte du fil ou depuis la fenêtre de détail.

- Vous avez une seule réaction par actualité : cliquer sur une autre réaction remplace la vôtre.
- Cliquer de nouveau sur votre réaction la retire.
- Le chiffre à côté de chaque réaction indique combien de personnes l'ont choisie ; votre réaction est mise en évidence.

## Commenter

1. Ouvrez la fenêtre de détail de l'actualité.
2. Dans la section **Commentaires**, écrivez votre texte dans le champ « Écrire un commentaire… » (1000 caractères au maximum, le compteur est affiché sous le champ).
3. Cliquez sur **Publier**, ou appuyez sur Ctrl+Entrée.

Pour supprimer un commentaire, cliquez sur la croix (**Supprimer**) à côté de sa date, puis confirmez. La croix n'apparaît que sur vos propres commentaires, sauf pour les administrateurs qui la voient sur tous les commentaires.

## Publier ou dépublier depuis le fil (administrateurs)

Les administrateurs voient une case **Publiée** en bas de la fenêtre de détail. La décocher retire l'actualité du fil ; l'enregistrement est immédiat.

## Gérer les actualités (administrateurs)

La gestion complète se fait depuis la page **Paramètres** (voir [Paramètres](/aide/parametres)), dans la partie consacrée aux actualités. Elle présente un tableau (**Titre**, **Date de publication**, **Statut** : Publiée ou Brouillon) et un champ **Rechercher** sur le titre.

### Créer une actualité

1. Cliquez sur **Ajouter une actualité**.
2. Renseignez **Titre**, **Résumé** et **Date de publication** (obligatoires ; la date est préremplie avec la date du jour), puis si besoin **Contenu complet**, **Lien** et **URL de l'image**.
3. La case **Publiée** est cochée par défaut : l'actualité sera visible dans le fil. Décochez-la pour garder un brouillon.
4. Cliquez sur l'icône disquette (**Sauvegarder**).

Le résumé s'affiche sur la carte du fil, le contenu complet dans la fenêtre de détail.

### Modifier une actualité

1. Cliquez sur l'icône œil (**Voir l'actualité**) de la ligne.
2. Cliquez sur l'icône crayon (**Modifier**), modifiez les champs.
3. Cliquez sur **Sauvegarder**, ou sur la croix (**Annuler**).

### Supprimer une actualité

Ouvrez l'actualité, cliquez sur **Supprimer** et confirmez.
